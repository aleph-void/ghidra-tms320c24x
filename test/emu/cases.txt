# Hand-computed expectations for the TMS320C24x p-code, worked out from the instruction descriptions
# in SPRU160C (TMS320F/C24x DSP Controllers CPU and Instruction Set Reference Guide), independent of
# the SLEIGH. Encodings are taken from the opcode column of the manual's instruction tables.
# Format: see C24xEmuTest.java. Code starts at code:0100 (word addresses); the pspec context defaults
# are SXM=1, OVM=0, PM=0 known; ARP and DP are read from the registers at run time.

expect ACC 0xfff92310
expect C 0
expect OV 0
end
