## Other implementations

`gh search repos` ("ghidra tms320c24x", "tms320c2xx sleigh", "tms320c20x sleigh") found no other implementation;
`ArapKBett/zoommulti` carries an unlicensed copy of this module. No code was borrowed from elsewhere.

## Ghidra-Rare changes (one commit each)

1. Removed the Ghidra skeleton plugin/loader/analyzer sources, `Makefile`, `buildTemplate.gradle`, `lib/`, `os/`,
   `ghidra_scripts/` placeholders and `data/` helper files (a processor-only module).
2. Rewrote the semantics: the instruction table is generated by `tools/gen_c24x.py`. The generator derives from
   Ghidra-Rare's own TMS320C2x/C5x generator (same project, same author as these tests), restricted to the C24x
   instruction set of SPRU160C with C2xx differences; this replaces the decode-only constructors, fixes the
   addressing (the old `ind` used the ARU field as a register number), adds ARP/DP/SXM/OVM/PM context
   tracking, carry/overflow/saturation, `*BR0+/-` reverse-carry, the repeat counter, the eight-level hardware
   stack, status-register load/store, conditions (BCND/CC/RETC accept every ZLVC/TP combination) and a
   big-endian word-order variant. New cspec (TI C convention: AR1 software stack), pspec context defaults, ldefs.
3. Notes, tests and build files: `GHIDRA-RARE.md`, `CREDITS.md`, `README.md` updates, `build.gradle`,
   `extension.properties`, `.gitignore`, `test/`.

## Sources and reference tools

Used as facts, black boxes or test inputs; nothing copied into the module:

- TMS320F/C24x DSP Controllers CPU and Instruction Set Reference Guide, SPRU160C (TI), for encodings and semantics.
- MAME `unidasm -arch tms320c5x` (GPL) as a black-box disassembler (the C5x opcode set contains the C2xx set).
- c5xtools by Grzegorz Worona (MIT): `c5xasm`, an independent assembler conformance-checked against TI's, used for
  the round trip and to assemble `test/real/demo24x.asm`; its nine TI-assembled example images (fetched by pinned
  commit and SHA-256, never committed) for the real-code comparison.
- Ghidra-Rare's TMS320C5x module, cross-checked on the shared subset.
